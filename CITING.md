# Citing the software

Use the repository title, version, repository URL, and exact commit when citing this implementation or its experimental artifacts. A citation should identify the implementation actually used, including whether a result comes from the capped public API or the uncapped experiment workflow.

The initial software version is **0.1.0**. The repository title is **Optimal Private Representations: Reference Algorithms and Reproducible Experiments**. The public repository is <https://github.com/MohitKumarRostock/optimal-private-representations>.

Record the exact revision used with `git rev-parse HEAD`. A moving branch name alone does not identify an immutable scientific result.

The citation record is independent of a manuscript. No manuscript author list, journal acceptance, or archival DOI is asserted by this repository. Maintainer-confirmed software attribution can be added to the citation metadata without changing the numerical record.
